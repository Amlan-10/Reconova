# Tech Stack Document (UI/UX-Aligned)  
**Product:** GST Reconciliation SaaS (Reconova)  
**Design Principle:** Modern SaaS UI, fast interactions, scalable architecture, AI-ready

---

## 1. Frontend Stack (Premium SaaS Experience)

### Core Framework
- **Next.js (React Framework)**  
Why:
- Fast performance (SSR/SSG)
- SEO ready (future marketing site)
- Ideal for SaaS dashboards

---

### UI Framework

- **Tailwind CSS**
- **shadcn/ui** (Highly recommended)
- **Framer Motion** (for animations)

Matches your design needs:
- Dark mode support (#020303)
- Custom green theme (#1C9719)
- Modern SaaS look

---

### Frontend Libraries

| Purpose | Tool |
|---------|------|
API calls | Axios |
Forms | React Hook Form |
Validation | Zod |
Charts | Recharts |
Tables | TanStack Table |
File Upload | React Dropzone |
Auth handling | NextAuth (optional) |

---

### Design System Implementation

Color Tokens:

```
Primary: #1C9719
Primary Hover: #224C1E
Background Dark: #020303
Surface: #E2E8E4
Text Secondary: #A3A3A3
Danger: #BE3A1F
```

Fonts:
- Inter (UI)
- JetBrains Mono (data / invoice view)

## 2. Backend Stack

### Core
- **Node.js**
- **Express.js** or **NestJS**

If you want scalable structure → **NestJS**

---

### Key Libraries

| Feature | Library |
|---------|--------|
Auth | JWT + bcrypt |
File upload | Multer |
CSV parsing | csv-parser |
Excel support | xlsx |
Validation | Joi / Zod |
Email | Nodemailer |

---

## 3. Database

### Primary
- **PostgreSQL**

Cloud Options:
- Neon (best)
- Supabase
- AWS RDS

---

### ORM (Important)

Use:
- **Prisma**

Why:
- Clean schema
- Type safety
- Easy migrations
- Works great with Next.js

---

## 4. File Storage

### MVP
- Local storage

### Production
- **AWS S3** or **Cloudflare R2**

For:
- Uploaded CSVs
- Generated reports

---

## 5. Reconciliation Engine

Runs in backend service.

- Large files
