# Product Requirements Document (PRD)

**Product Name (placeholder):** Reconova (change if you choose another)
**Version:** MVP – Phase 1
**Focus:** GST Reconciliation (Purchase vs GSTR-2B)

---

## 1. Product Overview

### Vision

To help businesses and CA firms automatically reconcile GST purchase data with GSTR-2B, identify mismatches, and prevent Input Tax Credit (ITC) loss.

### Objective (Phase 1)

Build a web-based SaaS that:

* Accepts purchase register and GSTR-2B
* Automatically reconciles invoices
* Highlights mismatches
* Provides actionable reports

---

## 2. Problem Statement

Businesses manually compare purchase data with GSTR-2B every month using Excel. This process:

* Takes 3–6 hours per client
* Is error-prone
* Leads to ITC loss
* Increases risk of GST notices

There is a need for an automated reconciliation system.

## 8. Functional Requirements

### 8.1 Authentication

* Email + Password
* JWT session

---

### 8.2 File Upload

Supported fields (Purchase CSV):

| Field          | Required |
| -------------- | -------- |
| Invoice No     | Yes      |
| Supplier GSTIN | Yes      |
| Invoice Date   | Yes      |
| GST Amount     | Yes      |

GSTR-2B fields:

* Invoice No
* Supplier GSTIN
* GST Amount

---

### 8.3 Reconciliation Logic

Matching Key:

```
Invoice No + Supplier GSTIN
```

Cases:

| Case                   | Status           |
| ---------------------- | ---------------- |
| Exact match            | MATCHED          |
| Invoice not in 2B      | MISSING_IN_2B    |
| GST amount differs     | AMOUNT_MISMATCH  |
| In 2B but not in books | MISSING_IN_BOOKS |

---

### 8.4 Dashboard Metrics

Show:

* Total Purchase Invoices
* Matched
* Missing in 2B
* Amount mismatches
* Total ITC at risk

---

### 8.5 Report Export

Excel columns:

| Invoice | GSTIN | Books GST | 2B GST | Status | Remark |
